Method

How a fault becomes a number.

Every cost in a record traces to a row in a published table and to the inputs you gave us. If it does not, the sentence does not ship.

How faults are costed

The audit finds the fault and keeps the evidence. The costing layer then turns it into a monthly figure.

  1. Input

    Your numbers

    Average deal value and monthly leads, as you give them. We do not estimate them for you.

  2. Table

    A cited conversion delta

    Each fault type maps to one row in a table of conversion deltas, with its source beside it.1

  3. Product

    Deal value × leads × delta

    The result is the cost per month of that fault, shown in the fault card with its severity and its fix.

  4. Review

    A person reads every fault

    The reviewer removes anything not worth your attention and signs the record.

How proof is run

The proof is the same appraisal, run again on the corrected site. The Proof Receipt uses the same layout as the Appraisal Record, so you compare page to page.
